# Arvind Kandari portfolio

A static personal portfolio for jobs, freelance opportunities, and professional branding.

## Deploy via GitHub Pages

1. Create a **public** repository called `arvind-portfolio` in your GitHub account.
2. Add the files from this folder to the **root** of the repository (not inside a subfolder).
3. In GitHub, open **Settings > Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then click **Save**.
6. Your published URL will be `https://YOUR-USERNAME.github.io/arvind-portfolio/`.
